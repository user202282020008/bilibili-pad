# B 站手柄倍速

用游戏手柄扳机的按压力度实时控制 B 站视频倍速，配合方向键、肩键、按钮实现完整的视频播放控制。

## ✨ 核心功能

### 🎮 扳机倍速控制
- **RT（右扳机）**：按压力度越大，播放越快（最高可达 16x）
- **LT（左扳机）**：按压力度越大，播放越慢（最低可达 0.1x）
- **松开扳机**：自动回到默认倍速
- **实时平滑**：倍速变化流畅自然，可调节平滑度

### 🎯 按键功能

| 按键 | 功能 | 说明 |
|------|------|------|
| **↑ / ↓** | 音量调节 | 每次 ±5%，长按连发 |
| **← / →** | 默认倍速 | 每次 ±0.25x，退出同步模式 |
| **A / B** | 快退 / 快进 | 每次 ±10 秒 |
| **L1（左肩键）** | 暂停 / 播放 | 切换播放状态 |
| **R1（右肩键）** | 字幕切换 | 循环：关 → 语言1 → 语言2 → ... → 关 |
| **X** | 宽屏模式 | 切换宽屏显示 |
| **Y** | 全屏模式 | 切换全屏播放；可在设置中改为循环：默认 → 宽屏 → 网页全屏 → 全屏 |

### 📺 HUD 实时显示
- **当前倍速**：大字显示，精确到两位小数
- **扳机进度条**：LT / RT 实时可视化
- **操作提示**：显示最后一次操作（音量、倍速、字幕等）
- **手柄状态**：显示连接的手柄型号

## 🚀 安装

### Chrome / Edge

1. 下载本项目到本地
2. 打开浏览器扩展管理页面：
   - Chrome: `chrome://extensions`
   - Edge: `edge://extensions`
3. 开启「开发者模式」
4. 点击「加载已解压的扩展程序」
5. 选择本项目文件夹

### 首次使用

1. 连接游戏手柄（支持 Xbox、PlayStation、Switch Pro 等标准手柄）
2. 打开任意 B 站视频页面
3. 左下角会出现 HUD，显示当前手柄状态
4. 按压扳机开始控制倍速

## ⚙️ 设置

点击浏览器工具栏的扩展图标打开设置面板：

### 倍速设置
- **RT 最大倍速**：右扳机全力按压时的倍速（1 ~ 16x）；可切换为「默认倍速 + 偏移量」模式（如 1x + 3 = 4x，跟随默认倍速变化）
- **LT 最小倍速**：左扳机全力按压时的倍速（0.1 ~ 1x）；可开启「LT 也加速」，两扳机叠加向最高速
- **默认倍速**：松开扳机时的倍速（0.25 ~ 8x）
- **同步播放器**：开启后默认倍速跟随网页播放器设置

### 控制设置
- **扳机死区**：低于此值视为未按压（0 ~ 0.5）
- **平滑时间**：倍速变化的平滑程度（0 = 关闭，0.08s 推荐）
- **交换扳机**：LT / RT 功能互换

### 功能开关
- **显示 HUD**：左下角的实时提示浮层
- **方向键音量**：↑↓ 调节音量
- **方向键倍速**：←→ 调节默认倍速
- **AB 快进退**：A / B 键 ±10 秒
- **L1 暂停**：左肩键暂停 / 播放
- **R1 字幕**：右肩键循环切换字幕
- **X 宽屏**：X 键切换宽屏模式
- **Y 全屏**：Y 键切换全屏模式
- **Y 循环播放模式**：开启后 Y 在 默认 → 宽屏 → 网页全屏 → 全屏 间循环（替代全屏开关）

## 📖 使用技巧

### 倍速控制
1. **键盘兼容**：B 站官方快捷键照常可用——长按 → 临时加速期间扩展自动让出控制权，↑↓ 调音量不冲突
2. **精准调速**：轻按扳机微调倍速，适合学习时逐句理解
3. **快速扫视**：全力按 RT 跳过无关片段
4. **慢动作分析**：全力按 LT 观看动作细节
5. **自定义基准**：方向键 ←→ 设置常用倍速（如 1.5x）

### 字幕控制
- 首次按 R1 会自动获取视频的所有字幕轨道
- 按 R1 循环切换：关 → 中文 → 英文 → 其他语言 → 关
- 字幕状态会自动保存，下次打开同一视频自动恢复
- 切换视频时字幕状态自动重置

### 多手柄支持
- 同时连接多个手柄时，优先使用正在操作的那个
- 扳机按压力度大的手柄获得控制权

## 🔧 高级配置

### 自定义倍速范围
在设置面板的输入框中可以输入超出滑块范围的精确值：
- RT 最大倍速：最高 16x
- LT 最小倍速：最低 0.1x
- 默认倍速：支持小数如 1.333x

### 同步模式 vs 自定义模式
- **同步模式**（默认）：默认倍速跟随播放器菜单设置
- **自定义模式**：使用固定的默认倍速，不受播放器菜单影响

## ❓ 常见问题

### Q: 没有检测到手柄？
**A**: 
1. 确保手柄已正确连接并开机
2. 在浏览器任意页面按一下手柄按键激活
3. 刷新 B 站视频页面
4. 部分手柄需要驱动程序（如 DS4Windows）

### Q: 倍速控制不生效？
**A**:
1. 检查扩展是否启用（工具栏图标）
2. 确认「总开关」已开启（设置面板第一项）
3. 尝试调大「扳机死区」避免误触
4. 直播页面不支持倍速控制

### Q: 字幕切换不灵？
**A**:
1. 确保视频有字幕（控制条上有字幕按钮）
2. 首次切换需要加载字幕列表，稍等 1-2 秒
3. 部分视频字幕需要登录才能使用
4. 刷新页面重试

### Q: HUD 不显示？
**A**:
1. 检查设置中「显示 HUD」是否开启
2. 全屏时 HUD 会移动到播放器内部左下角
3. 部分页面布局可能遮挡 HUD

### Q: 扩展图标显示「失联」？
**A**:
扩展被重新加载后，已打开的页面需要：
1. 点击扩展图标会自动重新注入脚本，或
2. 刷新页面重新加载

## 🛠️ 技术说明

### 兼容性
- ✅ Chrome / Edge / Opera（Manifest V3）
- ✅ B 站新旧版播放器
- ✅ 普通视频 / 番剧 / 课程
- ✅ Shadow DOM 播放器
- ❌ 直播页面（实时流不支持倍速）

### 手柄支持
基于标准 Gamepad API，理论支持所有符合标准映射的手柄：
- Xbox Series / One / 360 手柄
- PlayStation 5 / 4 手柄
- Switch Pro 手柄
- 其他标准 HID 游戏手柄

### 隐私说明
- ✅ 仅在 bilibili.com 域名下运行
- ✅ 配置数据存储在浏览器本地（chrome.storage.sync）
- ✅ 字幕数据从 B 站官方 API 获取（使用用户登录凭证）
- ✅ 不收集、不上传任何用户数据
